# 🏫 Django School Management System

A web-based school management system built using Django. This project allows administrators to manage student registrations, view student data, and handle user authentication (login/logout/change password).

---

## 🚀 Features

- 🌐 Homepage with navigation
- 📝 New Student Registration
- 📋 Show All Registered Students
- 🔍 Search Student by Name
- 🔐 Login / Logout / Change Password
- ✅ Admin Panel to manage students
